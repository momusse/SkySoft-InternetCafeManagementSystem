# Frontend - Internet Cafe Management System

This folder contains the web-based frontend interface developed using:
- HTML
- CSS
- JavaScript

## Features
- Add Customer
- Start / End Session
- Search Customer
- View Sessions
- Top-up Balance

## Notes
- This is a frontend prototype based on the console application
- Data is currently stored temporarily in browser memory

## How to run
▪️Open index.html in a browser
